# Reference

## 정의
**Reference(참조) 변수**: 기존에 선언된 변수를 가리키는 변수.
참조 변수를 선언한다는 것은 변수의 별명을 지어주는 것이라고 생각하면 된다.

## 알게 된 점
1. ⭐ 참조 변수는 초기화할 때 반드시 참조할 변수를 지정해야 한다.
   → `Null`이 될 수 없다.
2. 참조 변수는 주소값을 저장하는 게 아니다.
```cpp
   a = 10;
   aRef = a;
```
   → `aRef`에는 `a`의 값이 저장된다.
3. ⭐ 참조는 한 번 묶이면 다른 변수를 참조하도록 변경할 수 없다.
