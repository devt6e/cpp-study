# cpp-study

게임플레이 프로그래머 취업 준비를 위한 C++ 자기주도 학습 저장소.

## 학습 목표
- C++ 기초 문법부터 STL, 객체지향, 템플릿까지 체계적 학습
- UE5 C++ 이해를 위한 언어 기반 다지기
- 국내 게임사(넥슨, 크래프톤 등) 취업을 위한 코딩테스트 대비

## 환경
- Windows 11
- VSCode + MinGW-w64 (g++ 13.x)
- C++20 표준

## 진도

| 주차 | 주제 | 상태 |
|---|---|---|
| Week 1 | 참조, const, 포인터 심화 | 진행 중 |
